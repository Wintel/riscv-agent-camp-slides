注册 GitHub，
让小龙虾给你做个人主页

你只需要亲手做一件事：注册账号。建仓库、写网页、部署上线，全部交给小龙虾。做完你会拥有一个全世界都能打开的网址。

⏱️ 约 40 分钟 🧑‍💻 需先完成实验一 💰 完全免费 🌍 成品：一个真网址

这个实验在干什么？

一句话：你在 GitHub 开个户、配一把钥匙，剩下的——领地皮、盖房子、交付上线——全让小龙虾干。

做完以后，你会有一个这样的网址（把 你的用户名 换成你自己的）：

https://你的用户名.github.io

这个网址任何人、在任何地方、用手机都能打开。你可以发给爸妈、发给同学，写在简历上。

三个角色，先认清楚

角色是谁这次负责什么
🧑‍🎓 你老板注册账号、提供素材、批准操作、验收网页
🦞 小龙虾就是实验一装的 OpenClaw，住在你的板子里建仓库、写代码、提交、推送上线
🐙 GitHub全世界程序员放代码的地方，还免费送你一个网站空间存代码 + 把网页发布到互联网
💡 为什么只有注册要你自己来？

因为注册要过人机验证（那个"我不是机器人"的小游戏）—— 那道关卡就是专门用来拦住 AI 的。小龙虾确实是个机器人，它过不去，这活儿只能你干。 😄

但注册完之后，GitHub 的一切都能通过一个叫 API 的"程序专用入口"操作 —— 建仓库、传文件、查状态，小龙虾全都能自己来。你一行代码、一次鼠标点击都不用。

动手前的准备

  • ✅ 实验一已经做完——小龙虾能在浏览器里跟你聊天（左下角是绿点）
  • ✅ 一个能收邮件的邮箱（QQ 邮箱、163、Outlook 都行，用你常看的那个）
  • ✅ 想清楚你想在主页上放什么（名字、爱好、这几天在营里做了什么）
  • ✅ 隧道窗口还开着（就是那条 ssh -L 18789:...，关了就重开一次）
📶 关于网络

GitHub 在国内偶尔会慢或者连不上，这不是你操作错了。慢就等一等、刷新一下；实在不行叫助教，我们有加速地址（见卡住了怎么办）。

1注册 GitHub 账号 🐙

这一步只有这一步是纯人工。打开 👉 github.com/signup

1.1 填三样东西

它问什么你填什么注意
Email你常看的邮箱后面要收验证码，别填错
Password至少 8 位，含数字和小写字母记在手机备忘录里，别忘了
Username你的用户名⚠️ 看下面这条，很重要
⚠️ 用户名会变成你的网址，想好了再填

你填 xiaoming2026，你的主页就是 https://xiaoming2026.github.io。这串东西以后你会到处用它。

建议：用拼音 + 数字，全小写，短一点好记，比如 lixiaolong07、wangyu-sjtu。

不建议：xxx_666_tql 这种——三年后你在简历上写它会想删掉自己。 😅

只能用英文字母、数字和连字符 -，不能有中文、空格、下划线开头。名字被占了它会提示你，换一个就行。

1.2 过人机验证 + 邮箱验证

它会让你玩一个小验证（拖动/点图），然后往你邮箱发一个 8 位数字验证码。去邮箱抄过来填上。

📬 收不到验证码？

先看垃圾邮件箱（QQ 邮箱尤其爱把它扔那儿）。等 1～2 分钟再点"重新发送"，别狂点。

后面它会问你"团队多大""想用来干什么"之类的问卷 —— 随便选，或者直接点跳过（Skip），不影响任何事。看到要不要买收费版时，选 Free（免费版）。

✅
检查点：你能打开 https://github.com/你的用户名 并看到自己的头像页，就注册成功了。🎉

2给小龙虾办一把"万能钥匙" 🔑

还记得实验一里那把 DeepSeek 的钥匙吗？同样的道理再来一次：小龙虾要替你操作 GitHub 账号，得先证明"我是你派来的"。

GitHub 早就不让用密码了（太危险）。它给的是一种可以随时吊销、还能限定权限的钥匙，叫 Personal Access Token（个人访问令牌），下面简称 token。

拿到这把钥匙，小龙虾就能替你建仓库、传文件、查状态 —— 后面所有步骤你都不用再碰 GitHub 网页了。

2.1 创建 token

  1. 打开 👉 github.com/settings/tokens/new（这是 classic 版，最简单）
  2. Note（备注）：填 summer-camp，方便你以后认出它
  3. Expiration（有效期）：选 30 days —— 营结束后它自己失效，很安全
  4. Select scopes（权限范围）：只勾最上面那一个 repo
    🔐 为什么只勾一个？

    这叫最小权限原则：只给它干这件事必需的权力。repo = "可以新建、读写我的仓库"，正好够用 —— 建仓库和推代码都在这一项里。别的都不勾，万一钥匙丢了，损失也小。

  5. 拉到最下面点 Generate token

屏幕上会出现一串以 ghp_ 开头的字符，这就是 token：

ghp_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
⚠️ 又是"只显示一次"

跟 DeepSeek 那把钥匙一模一样：关掉页面就再也看不到了。立刻点复制按钮，粘到记事本里存好。

丢了也不用慌 —— 回来把它 Delete 掉，重新 Generate 一个，不花钱。

🔒 三条规矩（跟上次一样，但更重要）

1. 这把钥匙能改你 GitHub 上的所有仓库。别人拿到它，可以删你的东西、以你的名义提交代码。

2. 不要发群里、不要截图、不要写进网页文件里。特别注意：写进仓库里就等于发布到全世界，GitHub 还会自动扫出来并作废它。

3. 下一步要把它发给小龙虾 —— 这是必要的，它得拿着钥匙去开门。但发的时候顺手补一句："这个 token 只用来操作 GitHub，不要写进任何文件、不要打印出来。"

3让小龙虾替你建仓库 🦞

打开你的 OpenClaw 聊天页（http://localhost:18789）。从这里开始，你只需要打字。

先记住一条"魔法规则"

GitHub 有个特殊约定：如果一个仓库的名字正好等于 你的用户名.github.io，那么这个仓库里的网页会自动被发布成网站，不用做任何额外设置。

比如用户名是 lixiaolong07，仓库就得叫 lixiaolong07.github.io，网址就是 https://lixiaolong07.github.io。一字不差，全小写，中间是英文句点。

我们要用的就是这条魔法。你把规则告诉小龙虾，它去建：

发给 小龙虾 的话 · 建仓库
帮我在 GitHub 上新建一个仓库，我要用它做 GitHub Pages 个人主页。

- 我的 GitHub 用户名：[lixiaolong07]
- 仓库名必须正好是：[lixiaolong07].github.io
- 必须是 public（公开），否则网站发布不出来
- 不要初始化 README、不要 .gitignore、不要 license，我要一个完全空的仓库
- 我的 token：[ghp_把你的token粘在这里]

用 GitHub 的 API 建（curl 调 https://api.github.com/user/repos），
token 放在请求头里。建好之后：
1. 再查一次确认它真的存在、而且是 public；
2. 把仓库地址和我将来的网址告诉我。

重要：这个 token 只用来操作 GitHub。
不要把它写进任何文件、不要 echo 出来、不要提交进仓库。

它大概会这么干（你在屏幕上能看到）：

▶ 小龙虾正在干的事（示意） curl -X POST https://api.github.com/user/repos \ -H "Authorization: Bearer ***" \ -d '{"name":"lixiaolong07.github.io","private":false}' ← 建好了 curl https://api.github.com/repos/… ← 它在自己复查
🤖 什么是 API？

你平时用 GitHub 是点鼠标；程序不会点鼠标，所以网站另开了一个给程序走的门，这就是 API。

你在网页上点一下"Create repository"，和小龙虾发一条 POST /user/repos，在 GitHub 那边是同一件事。

这也是智能体能干活的根本原因：只要一件事有 API 或者有命令行，它就能替你做。

🙋 万一它建不出来（网络不通、token 不对）

先让它把报错原文贴给你，通常一眼就能看出是 token 错了还是网络不通。

实在不行你也可以自己去 github.com/new 点几下建（仓库名照上面的规则填、选 Public、什么都不要勾），然后回来告诉它"仓库我建好了，接着往下做"。能自己兜底，也是本事。

✅
检查点：浏览器打开 https://github.com/你的用户名/你的用户名.github.io，能看到一个空仓库，标签是 Public。这是你人生第一个由 AI 替你创建的东西。

4让小龙虾做网页 🦞

地皮有了，该盖房子了。接着在同一个聊天窗口里说下去（同一个会话它才记得你是谁、仓库叫什么）—— 我们开始用说话的方式编程。

4.1 先想清楚要放什么

AI 不认识你。你给的素材越具体，它做出来的东西越像你、越不像模板。花两分钟想想：

要素举例
你想被怎么称呼李小龙 / Xiaolong Li / 小龙
一句话介绍自己"某中学高二学生，喜欢拆东西和写小游戏"
3 个爱好 / 擅长的事打篮球、剪视频、Python 小脚本
这几天在营里做了什么"用 SSH 连上了一块 8 核 RISC-V 板子，让 AI 智能体在上面写了个测温脚本"
一句喜欢的话随便，一句歌词也算
想不想留联系方式可以不留。要留就留邮箱，别留手机号
🛡️ 这是公开网页，先记住三个"不要"

不要写手机号、家庭住址、身份证号、具体的班级。

不要放别人的照片和别人的真实姓名（同学的也不行——那是他们的隐私，不是你的）。

不要写"某某中学高二 3 班李小龙" —— 姓名 + 学校 + 班级凑在一起，就足够陌生人找到你了。写"上海某中学高中生"完全够。

完整清单见 附录 C，做之前扫一眼。

4.2 把活儿派给它

把下面这段整段复制到聊天框，把方括号里的内容换成你自己的，然后回车：

发给 小龙虾 的话 · 第一条
帮我在板子上做一个我的个人主页，纯静态网页，准备发布到 GitHub Pages。

请在 ~/mysite 目录里做，入口文件必须叫 index.html。

关于我：
- 称呼：[李小龙]
- 一句话介绍：[上海某中学高中生，喜欢拆东西和写小游戏]
- 爱好/擅长：[打篮球]、[剪视频]、[写 Python 小脚本]
- 最近在做：[参加交大学森暑期营，用 SSH 连上一块 8 核 RISC-V 板子，
  让 AI 智能体在上面写了个 CPU 测温脚本]
- 喜欢的一句话：[种一棵树最好的时间是十年前，其次是现在]

设计要求：
1. 单个 index.html 搞定，CSS 写在里面，不要引用任何外部网站的字体或库
   （不然打开会很慢）。
2. 手机上也要好看（响应式）。
3. 支持深色模式，跟随系统。
4. 有一个"关于我""我的爱好""最近在做什么"三段式结构，加一点淡入动画。
5. 配色干净，别用花里胡哨的渐变，字体用系统自带的中文字体栈。
6. 页面里不要出现我的手机号、学校班级等隐私信息。

做完先别管上线，把文件路径告诉我，我要先看看。

接下来盯着它干活，这才是这个实验最好看的部分：

  • 它会先 mkdir ~/mysite，然后真的动手写文件（不是把代码打印给你看）
  • 可能会跑 ls、wc -l 检查自己写没写完
  • 如果它觉得需求有歧义（比如"要不要放照片"），它会反问你 —— 回答它就行

4.3 先在板子上预览一下

上线之前当然要先看一眼。让它起一个临时的小服务器：

发给 小龙虾 的话
在 ~/mysite 里用 python3 起一个 http 服务，端口 8080，后台跑着，
然后告诉我怎么在我自己的电脑上看到它。

然后在你自己的电脑上再开一条隧道（第三个终端窗口，别关前面两个）：

在你自己的电脑上运行 · 新窗口
ssh -L 8080:127.0.0.1:8080 用户名@板子IP

浏览器打开 👉 http://localhost:8080

🚇 又是隧道？

对，跟实验一第 4 步一模一样的道理：网页跑在板子上，隧道把板子的 8080 号门接到你电脑门口。同一个套路你已经会用第二次了。

4.4 不满意就直接说

这才是用智能体开发的爽点 —— 你不用会 CSS，你只要会挑刺：

发给 小龙虾 的话 · 想改就改
标题太小了，放大一点。主色改成深蓝。
"我的爱好"那三项改成三个卡片并排，手机上再变成上下排列。
改完刷新给我看。
✅
检查点：在 localhost:8080 看到一个你自己满意的页面。满意了再往下走，上线以后改也行，但先改舒服一点更省事。

5让小龙虾把它送上线 🚀

网页在板子上躺着，只有你能看。现在让小龙虾把它推送到第 3 步它自己建的那个仓库里。

还是同一个聊天窗口，把下面这段发过去（只有邮箱那一处要换，仓库和 token 它刚才已经知道了）：

发给 小龙虾 的话 · 上线
把 ~/mysite 推送到你刚才帮我建的那个仓库，发布成 GitHub Pages。
用刚才那把 token，仓库地址和用户名你已经知道了。

- 我的邮箱（给 git 提交用）：[我的邮箱@example.com]

请你：
1. 在 ~/mysite 里 git init，分支叫 main。
2. 先检查一遍要提交的文件，确认里面没有 token、没有密码、没有我的隐私信息，
   列给我看一眼。
3. 配好 git 的 user.name 和 user.email，提交信息写 "我的第一个个人主页"。
4. 推送到那个仓库的 main 分支。

重要：token 只用来推送。
不要把它写进任何文件（包括 .git/config 里的 remote 地址），
不要 echo 出来，不要提交进仓库。
推送完成后告诉我我的网址是什么，以及大概多久能打开。
🤨 为什么特意提"不要写进 .git/config"？

因为最省事的推送写法是把 token 直接塞在仓库地址里（https://token@github.com/...），那样它会被存进本地的 .git/config 文件里 —— 板子是公用的，下一个同学就能翻到。

你这一句话，就是在教它用更安全的写法（比如只在这一次推送时临时带上）。让 AI 干活的人，得比 AI 多想一步。

它会依次做这些事，你在屏幕上能一条条看到：

▶ 小龙虾正在干的事（示意） git init -b main git add -A git status ← 它在自查有没有夹带私货 git config user.name / user.email git commit -m "我的第一个个人主页" git remote add origin https://… git push -u origin main ✔ 推上去了
🛑 它会先请示你

还记得实验一第 5 步那个请示框吗？git push 属于"会影响外部世界"的操作，它大概率会弹框问你。

看清楚命令再点「允许」 —— 这个习惯比这次实验本身更重要。

🐢 推送很慢或者失败？

GitHub 在国内不太稳。让它重试两次；还不行就告诉它："用 https://gh-proxy.com/https://github.com/... 这个加速地址再试一次。"

6全世界都能看到了 🌍

推送成功后，GitHub 需要大约 1～2 分钟把你的网页发布出去（第一次可能要 3 分钟，耐心点）。

然后打开：

在任何浏览器里打开 · 手机也行
https://你的用户名.github.io
😐 显示 404 怎么办？

八成是还没发布完，等 2 分钟，然后按 Ctrl + Shift + R 强制刷新。

还是 404 的话，去仓库页面点 Settings → Pages 看一眼状态；或者检查这三件事：仓库是不是 Public、仓库名是不是一字不差、根目录下有没有 index.html。

🎉
检查点：用你的手机（关掉 WiFi，用流量）打开这个网址。能看到 —— 说明它真的在互联网上了，而不只是在你的电脑里。把网址发给爸妈看看。
🤯 想一想刚刚发生了什么

你没写一行 HTML、没背一条 git 命令，但你现在拥有一个真实的、全球可访问的网站。

过程里你干的事是：说清楚要什么 → 检查它做得对不对 → 批准关键操作。

这就是这门课想教你的东西。不是"AI 替你做作业"，而是你当项目负责人，AI 当施工队。

7继续改它（这才是刚开始）

上线之后再改，流程简单得多：改文件 → 再推一次 → 等 1 分钟。而这两步还是它干。

发给 小龙虾 的话 · 改完顺手上线
在主页上加一个"暑期营记录"板块，写我这四天学到的东西：
第一天连上板子学 Linux，第二天给板子装了 AI 智能体，
第三天让它写程序，第四天做了这个网页。
做成一条竖着的时间线，每一项有个小图标。
改完直接 commit 并 push 上线，然后告诉我什么时候能刷新看到。

还可以让它加点什么

想法直接这么说
放张照片"我把照片放在 ~/mysite/me.jpg 了，圆形头像放在标题旁边"（放风景/宠物比放自己的正脸更稳妥）
加个手动深浅色开关"右上角加一个切换深浅色的按钮，选择要记住"
展示营里的作品"加一个项目卡片，写我的 cpu_temp.py 干什么用，附上代码片段"
加个访客彩蛋"页面底部加一句每次刷新都不一样的随机格言"
让它自己挑刺"你自己审一遍这个页面，从手机适配、无障碍、加载速度三个角度挑 5 个问题并修好"
💡 最后一条最值得试

让 AI 批评自己的成果，往往比你自己憋着想改哪里更有效。这招在任何任务上都好用。

📎 附录 B · 背后到底发生了什么？

四个概念，一次讲明白。以后你会一直用到它们。

git 是什么

一台时光机。每次 commit 都是给你的文件夹拍一张照片，存下来。改坏了可以回到任何一张照片。它记录的是"谁、什么时候、改了哪一行"。

GitHub 是什么

git 是本地的时光机，GitHub 是放在云上的备份 + 广场。push = 把你本地的照片上传上去。全世界的开源代码都堆在那儿。

GitHub Pages 是什么

GitHub 附带的免费虚拟主机。它看到你仓库里有 index.html，就把它当网站放到互联网上，还免费送你 HTTPS。

🏫 你正在看的这个页面就是这么来的

这门课的所有讲义 —— 包括你现在读的这一页 —— 就放在 GitHub 上，用 GitHub Pages 发布的。你刚做的事和老师做的事，是同一件事。

为什么叫"静态网站"

因为服务器不做任何计算，就是把 .html 文件原封不动发给浏览器。优点：飞快、免费、几乎不会宕机、没有后端可以被黑。个人主页、博客、课程讲义，用静态就够了。

📎 附录 C · 上线前的隐私清单

公开网页 = 全世界（包括搜索引擎、包括陌生人）都能看。点「push」之前，把这张表过一遍。

内容能放吗说明
