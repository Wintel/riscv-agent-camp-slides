投稿

怎么让你的作品上这一页

不限形式：网页、脚本、小游戏、板子上跑的小工具都算。

📬 三步搞定

  1. 让它能被打开。网页最省事 —— 用选修实验那套办法发到 GitHub Pages，你就有了一个网址。不是网页的话，把代码放个仓库、或者直接把文件发给助教。
  2. 把这几样发给助教：作品名字、一两句介绍（它是干什么的）、网址或代码、你的姓名和小组。
  3. 等它出现在这一页。老师会加上来，你就可以把链接发给爸妈和同学了。
🔒投稿前自己检查一遍：作品里不要出现手机号、家庭住址、班级、别人的真名和照片，也不要有任何 API key / token。这一页是公开的，全世界都能看到。
