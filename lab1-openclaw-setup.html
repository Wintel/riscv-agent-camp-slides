实验一 · 配套第 2 讲

从零把 AI 智能体
装进你的板子

跟着做完，你会拥有一个住在自己板子里、听得懂人话、会自己动手干活的 AI 助手。

⏱️ 约 30 分钟 🧑‍💻 零基础可跟做 💰 花费约 10 元 🖥️ Windows / Mac 都行

这个实验在干什么？

一句话：把 OpenClaw 装进板子，让它借 DeepSeek 的"大脑"，替你操作这台 RISC-V 电脑。

三个角色，先认清楚，后面就不会晕：

角色是谁在哪
🧑‍🎓 你发号施令、验收结果你自己的电脑
🦞 OpenClaw智能体本体，会跑命令、写文件住在板子里
🧠 DeepSeek大模型，负责"思考"云端机房，靠你的 key 进门
💡 好消息

你自己的电脑上什么都不用装——有个 SSH、有个浏览器就够了，它俩 Windows 和 Mac 都自带。

动手前的准备

  • ✅ 一台能上网的电脑（Windows 10 以上 / Mac 都行）
  • ✅ 板子的 IP 地址、用户名、密码（老师会写在黑板上）
  • ✅ 微信或支付宝（第 1 步充值用，10 块钱就够这几天了）
  • ✅ 第 1 课学的 ssh 命令 —— 今天就要用上了

1给自己办一把钥匙 🔑

大模型住在云端的机房里。板子上的 OpenClaw 每"想一步"，都要远程去请它帮忙。而机房不是随便谁都能进的——你得有一张门卡，这就是 API key。

我们用 DeepSeek（国内的大模型，直连很快，还便宜）。

1.1 注册

打开 👉 platform.deepseek.com，用手机号注册、登录。

1.2 充值

进入左边的「充值」页面，充 10 元（支付宝、微信都行）。

💰 会花很多钱吗？

不会。DeepSeek 按用量收费，便宜到什么程度呢——你这几天来回问上千句，也就几块钱。充 10 块完全够用，用不完还在你账号里。

1.3 创建 API key

进入左边的「API keys」页面 → 点「创建 API key」→ 随便起个名字（比如 summer-camp）→ 创建。

屏幕上会出现一长串以 sk- 开头的字符，这就是你的钥匙。

⚠️ 这一步最容易翻车，看清楚

这串字符只会完整显示这一次！关掉窗口就再也看不到了。

立刻点「复制」，粘贴到一个安全的地方（比如你电脑上新建一个记事本）。

万一没存住也别慌 —— 删掉重新创建一个就行，不花钱。

🔒 关于这把钥匙的三条规矩

1. key 就是你的钱包。别人拿到它，就能用你的余额。

2. 不要发到群里、不要发给同学、不要截图发朋友圈。

3. 一会儿粘贴 key 的时候，要粘到脚本问你的那个位置，❌ 千万不要粘到跟 AI 的聊天框里 —— 那等于把钥匙念给全世界听。

2连上你的板子

打开终端：

  • Windows：开始菜单搜索 PowerShell，打开它
  • Mac：聚焦搜索（⌘ + 空格）输入 终端，打开它

输入下面这行（把 用户名 和 板子IP 换成黑板上的真实信息）：

在你自己的电脑上运行
ssh 用户名@板子IP

比如：ssh student@192.168.1.50

第一次连接会问你 Are you sure you want to continue connecting? —— 输入 yes 回车。然后输入密码。

⌨️ 输密码时屏幕上没反应？

这是正常的。Linux 输密码时不显示任何字符，光标也不动，这是为了防止旁人看到。盲打完直接回车就行，别以为卡住了反复输入。

✅
检查点：看到提示符从你自己电脑的名字变成了板子的名字，就说明你已经"人在板子里"了。🎉

3一键安装

现在你在板子里。复制下面这一整行，粘贴进去回车：

在板子上运行
curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/Wintel/riscv-agent-camp-slides/main/setup-openclaw.sh -o setup-openclaw.sh && bash setup-openclaw.sh
📋 怎么粘贴？

Windows 的 PowerShell 里点鼠标右键就是粘贴；Mac 用 ⌘ + V。

脚本会自己走完 8 个步骤，你只需要在 第 5 步 做一件事——把第 1 步存好的那串 sk-... 粘贴进去，回车：

请粘贴你在 platform.deepseek.com 创建的 API key， 它以 sk- 开头。粘贴时屏幕上不会显示任何字符，这是正常的。 API key: ▊
😱 粘贴完屏幕上什么都没出现？

正常！这是故意的，防止旁边的同学看到你的钥匙。放心回车就行。

然后就是等。最慢的是"安装 OpenClaw"那一步，大约 1 分钟，别以为卡住了。全部顺利的话，最后你会看到：

▶ 第 8 步 / 共 8 步：自检（真的问它一句话，约 20 秒） ✔ 它回话了：…… ===================================================== 🎉 装好了！下面两步在「你自己的电脑」上做 =====================================================
🛑 先别关这个窗口！

最后那段话里有两条属于你自己的信息（隧道命令、网页地址），下一步就要用。

4开一条隧道，把聊天页"搬"到你电脑

为什么要多这一步？

你可能会想：板子已经在跑了，我直接在浏览器里输 板子IP:18789 不就完了？

试了你会发现打不开，浏览器会报一句 control ui requires device identity。

原因是浏览器有条安全规矩：只有 localhost（也就是"本机"）和 HTTPS 网站，才被允许使用某些敏感功能。而 OpenClaw 的控制台正好需要这些功能。直接用 IP 访问的明文网页，浏览器信不过，直接拒绝。

🚇 解决办法很聪明，叫「SSH 端口转发」

打个比方：板子的 18789 号门在很远的地方，浏览器不肯走那么远。

那我们就用 SSH 挖一条隧道，把那扇门"接"到你自己电脑的门口。于是浏览器以为门就在本机（localhost），高高兴兴地开了。

而数据在隧道里是加密的，比直连还安全。

动手

在你自己的电脑上新开一个终端窗口（原来那个连着板子的别关），粘贴脚本最后打印给你的那行，长这样：

在你自己的电脑上运行 · 新窗口
ssh -L 18789:127.0.0.1:18789 用户名@板子IP

输入密码。看起来好像什么都没发生，就是一个普通的板子提示符——这是对的。

🚨 这个窗口必须一直开着

关掉隧道就断了，网页立刻失联。你可以把它最小化，但别关掉。

打开网页

在你自己电脑的浏览器里，打开脚本最后给你的那个地址：

在你自己电脑的浏览器里打开
http://localhost:18789/#token=你自己的那串口令
🔑 #token= 后面那串不能少！

那是开门的口令，第一次打开必须带着。打开后你会发现它自己从地址栏消失了——这是 OpenClaw 故意的，防止被别人看到。之后同一个标签页刷新不用再带。

🎉
检查点：看到聊天界面，而且左下角是一个绿点，就成功了！

5说第一句话

它可能先反问你

第一次聊天，它八成会先问你「我该叫什么名字？你是谁？」——

🤝 这不是出错了

它是在给自己和你建档（就像新同学互相认识）。随便回答就行，比如"你叫小爪，我叫小明"。之后它就记住了。

试试这三句

① 先来个简单的（看它会不会用工具）

发给 AI 的话
这块板子的硬盘还剩多少空间？

注意看：它不会凭空瞎猜，而是真的跑了一条 df 命令，把结果读给你听。这就是"智能体"和"聊天机器人"的根本区别。

② 让它动手写程序

发给 AI 的话
写一个 cpu_temp.py：每 2 秒读一次这块板子的 CPU 温度，带时间戳记进 temp.log。
写完实际跑 6 秒，把 temp.log 的内容给我看。
🔍 这里有个好玩的地方，你一定要盯着看

大多数电脑的温度是从 /sys/class/thermal/thermal_zone0 读的，但我们这块 RISC-V 板子偏偏没有这个文件。

你会看到它先试了一下、失败了，然后自己换个地方找，最后在 hwmon 里找到了板子真正的温度传感器（叫 corepvt-ultrarisc，是 SoC 内部的探针）。

这就是"想 → 做 → 看 → 再转一圈"的循环，也是你请它干活、而不是自己查资料的意义。

③ 让它请示你（观察安全机制）

发给 AI 的话
把 /tmp 下面所有 .log 文件删掉

它在动手前会弹出一个请示框，列出准备执行的命令，让你选「允许一次 / 总是允许 / 拒绝」。

🛡️ 认真看清楚再点

这道关卡就是你的安全带 —— 它可以很能干，但真正拍板的人始终是你。

拿不准的时候，选「拒绝」，然后问它"你为什么要跑这条命令？"

🔧 卡住了怎么办

你看到的什么原因怎么办
Permission denied密码错了重新输。密码不显示是正常的，别重复输入
脚本说架构不对你在自己电脑上跑脚本了先 ssh 连上板子，在板子里跑
卡在"安装 OpenClaw"正常，板子性能有限耐心等 1～2 分钟
这不像一把 DeepSeek 的 key复制时少了字符回官网重新复制，或重新创建一个
网页打不开 / 一直转圈隧道窗口关了重新开终端，再跑一次 ssh -L ...
requires device identity你直接用板子 IP 访问了必须用 localhost 那个地址（见第 4 步）
说要认证 / 连不上 Gateway地址里少了 #token=...用脚本最后给的完整地址重新打开
左下角是红点板子上的 Gateway 停了回板子上再跑一次 bash setup-openclaw.sh
它答非所问、瞎编大模型的通病把报错原文贴给它；或开个新会话重来
⚠️ 三条保命提醒

1. 🚫 千万别运行 pkill -f openclaw。你的 SSH 连接的命令行里也含 "openclaw" 这几个字，这条命令会把你自己一起踢下线。要重启就直接再跑一次安装脚本。

2. 🔑 换 key 怎么办？删掉 ~/.openclaw 文件夹，再跑一次脚本即可。

3. 🌐 别把控制台开放到公网。它能操作你的板子，只在校园网里、只走隧道用。

📎 附录 B · 脚本到底做了什么？

一键脚本不是魔法，它只是替你敲了这些命令。看懂它，你就能自己装了：

步骤干了什么为什么
0检查是不是 riscv64、能不能连上 DeepSeek早点发现问题，省得装到一半才报错
1下载 Node 24 到 ~/openclaw-env板子自带的 Node 是 18，版本太老跑不了
2npm install -g openclaw@latest装 OpenClaw 本体（走国内镜像，快很多）
3往 ~/.bashrc 加一行 PATH让你下次登录直接敲 openclaw 就能用
4装 @openclaw/deepseek-provider 插件让 OpenClaw 学会跟 DeepSeek 说话
5openclaw onboard 填入你的 key把你的钥匙交给它保管
6配置只监听本机 + 随机口令外人进不来，只能走你的 SSH 隧道
7后台启动 Gateway那个 7×24 待命的"管家"进程
8真的问它一句话确认整条链路是通的，而不是"看起来装好了"

📎 附录 C · 关于模型

装好后默认用的是 deepseek-v4-flash（快、便宜，够用）。在网页右下角能看到当前模型。

你可能会奇怪：为什么只有 DeepSeek 一个选项？

因为 OpenClaw 内置支持 80 多个模型（Claude、GPT、Gemini 都在列），但每一个都需要那一家的 API key 才能用。我们只办了 DeepSeek 的门卡，所以只有这一扇门能进。这正好说明了 key 的作用。

⚠️ 别选这两个

如果你自己去翻配置，会看到还有 deepseek-chat、deepseek-reasoner 两个名字 —— 它们已经在 2026 年 7 月下架了，选了会报错。就用默认的 v4-flash。

祝你玩得开心。有任何问题，举手叫老师或助教。 🚀
