# 可直接交给 OpenClaw / DeepSeek 的部署提示词

请解压随消息提供的 `mario-world1-riscv-openclaw-bundle.tar.gz`，部署其中的 `mario-pixel-quest` 项目。

目标机器是一块 RISC-V Linux 板，局域网 IP 为 `192.168.31.105`。端口 `8000` 和 `8080` 已被其他服务占用，严禁停止、覆盖或修改这两个服务。优先使用端口 `3001`；启动前先用 `ss -ltn` 检查，若 `3001` 也被占用，则自动选择 `3002`、`3003` 等空闲端口，并在完成信息中明确告诉我最终地址。

要求：

1. 阅读 `README.md`、`RISCV_DEPLOY.md`、`package.json` 和源码后再执行。
2. 保留完整功能：World 1–1 至 1–4；标题为 SUPER WANGJIAN；1–2 的地表入口、地下主路线、27 金币隐藏房、14 只栗宝宝、3 只绿乌龟、1 只红乌龟、无食人花、四座成对反向移动升降台、正常出口地表和屋顶 Warp Zone；1–1 至 1–3 的旗杆下滑/降旗/进城堡/城堡升旗完整过关动画；人物选择；经典马里奥；王健的站立/奔跑/跳跃/庆祝动作；两名角色各自适配的蘑菇保护框；切换关卡保持当前角色；键盘和触控操作、声音开关、计分、金币、生命和关卡衔接。
3. 使用 Node.js 22.13 或更高版本和 pnpm；优先执行 `corepack enable`、`pnpm install --frozen-lockfile`、`pnpm build`、`pnpm start:riscv`。
4. 服务必须绑定 `0.0.0.0`，以便局域网访问；不要发布到公网，不要配置外部云服务。
5. 不要改动 `8000`、`8080` 上的任何进程，不要执行破坏性系统命令。
6. 如果依赖缺少 RISC-V 预编译版本，保持玩法和视觉不变，将项目转换为浏览器可直接运行的纯静态版本；继续使用 `public/character-sprites.png`，不得替换或重新生成该人物。
7. 先执行 `pnpm test`，再成功启动服务；用本机 `curl` 验证首页返回成功状态，并检查 HTML 中包含“选择人物”“经典马里奥”“王健”。不要删除或跳过 `tests/` 中的回归测试。
8. 最终仅报告：实际执行的关键步骤、最终监听端口、局域网访问 URL、进程守护方式，以及是否通过启动验证。

预期默认访问地址：`http://192.168.31.105:3001/`。

## 产品原始需求提示词

> 在新文件夹中制作一个高精度的马里奥小游戏，不用发布网站。补全 World 1–1 至 1–4，按原版地图网格复刻，修正 1–1 金币位置。World 1–2 按原版全图重做地表入口、地下主路线、27 金币隐藏房、敌人数量与位置、三根中段管道、移动升降台、正常出口地表、旗杆城堡和屋顶 Warp Zone。提高跳跃高度。把所给像素人物“王健”做进游戏，开局提供人物选择，人物选择必须跨关卡保持。为马里奥和王健分别适配蘑菇保护框。键盘、鼠标和触控都应可操作。最终打包全部源码、资源、说明与提示词，供 RISC-V 板上的 OpenClaw/DeepSeek 部署。
