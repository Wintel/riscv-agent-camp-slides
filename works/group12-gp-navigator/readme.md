一、前置：F1专业系统名词通俗科普（代码内注释同步附上，方便读懂逻辑）
1.DRS（可变尾翼系统）
名词解释：赛车尾翼上层挡板可电动抬起，减少空气阻力提升直线速度；仅赛道指定直道区域、跟车差距1秒内才能开启，开启后弯道抓地力下降，现实F1核心超车工具。
2.轮胎配方策略（软/中性/硬胎）
名词解释：三种不同橡胶轮胎，软胎抓地力最强、升温快、磨损极快；硬胎耐磨、圈数多、低速弯道抓地力弱；中性胎平衡两者，玩家需要规划什么时候进站更换轮胎。
3.进站换胎/Undercut/Overcut战术
名词解释：维修区更换轮胎操作；Undercut=提前进站换新胎，靠新胎速度追上前方旧胎对手；Overcut=晚进站，利用旧胎跑完更多圈，进站后实现反超。
4.维修区限速罚时
名词解释：维修通道强制限速，超速会叠加额外罚时加到总比赛时间内，模拟真实赛事规则。

二、整体画质、物理与基础规范（目标+实现方案）
1.渲染标准
【功能目标】实时3D渲染，车漆反光、赛道水渍光影、动态阴影、空气光晕、高速动态模糊，帧率稳定无穿模。
【实现方案】采用基础实时PBR渲染管线；赛车模型分层材质（金属车漆、橡胶轮胎、碳纤维尾翼）；赛道地面增加多层纹理（沥青、草地、缓冲区、积水反光层）；给高速赛车挂载动态模糊后处理滤镜，速度数值越高模糊强度越大；模型碰撞盒精细化，杜绝穿模BUG。
2.F1赛车物理引擎（包含DRS联动物理）
【功能目标】还原空气下压力、高速惯性、刹车阻尼、DRS开合直接改变车辆操控手感，加速带屏幕震动反馈。
【实现方案】给赛车搭建独立物理参数表：整车质量、重心高度、空气下压力基础值、轮胎抓地力系数；新增DRS开关布尔变量，DRS开启时：下压力数值降低35%、风阻降低20%、车辆极速提升15km/h；DRS关闭自动恢复原始空气动力学参数；油门深度绑定加速度曲线，刹车绑定线性减速阻尼；车速大于200km/h时触发画面震动脚本。
3.操作端适配
【功能目标】电脑键鼠、手机触屏双适配，操作零延迟。
【实现方案】做两套独立输入映射系统：电脑端键盘绑定转向/油门/DRS/视角切换；移动端虚拟摇杆+屏幕触控按钮；输入信号做帧同步处理，消除操作延迟。
4.交付硬性标准
【功能目标】完整可运行全套代码，三大流程无缝串联。
【实现方案】代码按模块拆分：开场动画模块、竞速核心模块、维修策略模块、颁奖结算模块；每个模块独立函数，通过场景切换接口自动串联，无需手动跳转场景。

三、第一模块：赛前电影级开场动画（对标QQ飞车前置CG，目标+实现方案）
1.全程电影运镜
【功能目标】丝滑动态镜头、激昂BGM同步播放，完整展示赛道全貌。
【实现方案】创建预设关键帧动画轨道，按时间轴自动切换相机坐标、旋转角度；音频轨道绑定引擎轰鸣BGM，镜头切换同步调节音量；镜头运动采用缓入缓出插值算法，避免镜头抖动。
2.赛道镜头展示流程
【功能目标】依次展示赛道全景→弯道特写→DRS长直道→看台细节→锁定发车格。
【实现方案】时间轴关键帧顺序：①高空远镜头俯瞰完整赛道 ②相机俯冲切入连续弯道特写 ③镜头平移到长直道，屏幕弹出文字标注“DRS激活区域” ④近距离拍摄观众席、护栏模型 ⑤镜头缓慢下沉，锁定全部发车赛车。
3.发车赛车展示
【功能目标】多台F1赛车整齐停放，标注DRS区、维修区入口位置。
【实现方案】实例化多台赛车模型，按发车排位坐标摆放；赛道地图上标记两个透明触发区域：DRS检测区、维修区入口，半透明文字悬浮标注位置。
4.321GO倒计时跳转比赛
【功能目标】倒计时结束自动进入竞速对局，附带爆光特效。
【实现方案】UI画布创建红色大号数字动画，3/2/1逐帧缩放淡出；归零瞬间触发全屏闪光粒子特效、引擎震动音效；执行场景切换函数，销毁动画场景，加载竞速对局场景。

四、第二模块：核心竞速对局（重点：DRS系统+进站换胎策略，目标+完整实现方案）
1.五套一键无缝切换视角
【功能目标】对局任意时刻无延迟切换5类视角，座舱仪表盘同步展示DRS、轮胎数据。
【实现方案】创建5组相机预设参数，绑定切换快捷键；每次切换直接赋值相机坐标、距离、旋转参数，无加载卡顿；第一人称座舱内搭建虚拟仪表盘UI，实时读取全局变量：DRS状态、轮胎磨损百分比、剩余油量，实时刷新屏幕数值。
①座舱第一人称：相机固定驾驶舱内部，方向盘、仪表盘模型可见
②车头前置视角：相机固定赛车前端，无座舱遮挡
③第三人称尾随视角：相机绑定跟随脚本，赛车转弯/加速自动自适应距离
④高空上帝视角：固定高空俯视相机，完整展示整条赛道地图
⑤动态电影视角：检测超车、过弯、DRS加速事件，事件触发自动临时切换特写镜头

2.完整DRS可变尾翼系统（严格复刻F1规则）
【功能目标】直道分检测区+激活区、1秒差距限制、DRS开合改变极速与抓地力、多类视觉提示。
【分步实现方案】
①赛道区域划分：在长直道创建两个矩形碰撞触发器：DRS检测点、DRS激活段；赛车驶入检测点后，程序计算当前赛车与前车的单圈时差。
②权限判定逻辑：if 时差<1秒 + 当前位置在DRS激活直道 + 不在弯道/维修区 → DRS按键解锁可用；其余全部情况锁定DRS，按键无响应。
③模型与物理联动：按下DRS按键，赛车尾翼模型执行抬起动画，同步修改车辆空气动力学物理参数（降低下压力、减少风阻提升极速）；松开按键，尾翼闭合，物理参数复原。
④全场景视觉提示：仪表盘绿色DRS指示灯亮起、车尾生成蓝色气流粒子光效、屏幕右侧悬浮文字“DRS已激活”提示。

3.进站换胎+轮胎策略完整系统
【功能目标】赛前预设轮胎方案、实时轮胎磨损、进站完整换胎动画、Undercut/Overcut AI战术、维修区超速罚时。
【分步实现方案】
①三种轮胎参数配置表：
软胎：抓地力系数+30%，单圈极限速度高，每圈磨损值+8；
中性胎：抓地力系数+15%，每圈磨损值+4；
硬胎：抓地力系数0，每圈磨损值+1，耐磨圈数最多；
开局弹窗UI，玩家自由选择起步轮胎、预设1-3次进站计划。
②轮胎磨损实时演算：赛车每行驶10米，四条轮胎磨损数值同步增加；磨损超过80%后，轮胎抓地力系数线性下降，同时生成轮胎冒烟粒子特效；UI面板实时显示4条轮胎磨损百分比。
③维修区整套逻辑：

维修通道添加限速碰撞区域，赛车驶入区域后强制最高速度60km/h；车速超过阈值，全局罚时变量+5秒，屏幕弹出超速罚时提示。
赛车驶入维修工位触发动画：千斤顶升起车身、多名工人模型执行更换轮胎动态动作，动画持续2.5秒（模拟真实换胎耗时）。
进站过程弹出策略选择UI：可更换软/中/硬胎、补充燃油；确认后刷新轮胎磨损数值、更新车辆抓地力参数。
④AI战术逻辑：AI实时读取自身轮胎磨损数据，磨损达到阈值自主驶入维修区；部分AI提前进站（Undercut），部分AI延后进站（Overcut）；AI会利用DRS系统完成超车，模拟真人博弈。
4.驾驶操控与全局数据面板
【功能目标】基础操控齐全，屏幕实时展示全部赛事关键数据。
【实现方案】绑定输入：左右转向、油门、刹车、DRS快捷键、视角切换键；UI固定悬浮面板实时渲染：时速表、剩余圈数、单圈计时、前后车时差、DRS可用状态、四条轮胎磨损、剩余油量、距离维修区距离、总罚时。
5.动态竞速特效
【功能目标】尾气、轮胎白烟、DRS气流、高速反光等特效全覆盖。
【实现方案】给赛车挂载多个粒子生成器：过弯侧滑触发白烟粒子、油门踩满生成尾焰、DRS开启专属蓝色气流粒子；阳光直射路面添加动态反光光斑。

五、第三模块：冲线结算+全套F1颁奖典礼（对标QQ飞车赛后流程，目标+实现方案）

②灯光系统：多组聚光灯实体锁定领奖台，循环闪烁明暗；
③粒子特效：全屏持续飘落彩带、空中循环燃放烟花；
④奖杯模型动画：奖杯缓慢升起展示；
