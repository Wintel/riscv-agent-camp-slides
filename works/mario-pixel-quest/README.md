# Super Wangjian · Pixel Quest —— 线上产物

第 6 组（龚R垚 · 乐J纬）的作品，NES 风格横版像素游戏，重建了 World 1 的四关。

这个目录是**构建产物，不要手改**。源码和构建方法在 `../mario-pixel-quest-src/`。

## 玩法

- `←` `→` 或 `A` `D` 移动，`Space` / `W` / `↑` 跳跃，`Shift` / `X` 加速，`P` / `Esc` 暂停
- 站在可进入的竖直管道顶端按 `↓` / `S` 进管道
- 手机平板用屏幕下方的虚拟按键
- 开局可选经典马里奥或王健；过关后按 `Enter` 进下一关，人物、分数、金币、生命都保留
